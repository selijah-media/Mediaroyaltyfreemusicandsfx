# Media: Royalty-Free Music & Sound

A static, mobile-friendly GitHub Pages website. No build tools or paid hosting needed.

## Publish with GitHub Pages
1. Create a new **public** GitHub repository, e.g. `media-royalty-free-sound`.
2. Select **Add file → Upload files** and upload `index.html`, `style.css`, and `script.js` (at the repository root, not inside a folder).
3. Commit the changes.
4. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select **main** and **/(root)**. Save.
5. Once deployment finishes, your site is available at `https://YOUR-USERNAME.github.io/media-royalty-free-sound/`.

## Update the resources
Edit the `resources` array near the top of `script.js`. Use `type:'music'` or `type:'sfx'` to keep the two categories separate. Each card links directly to the resource's free-use area where possible. Logos use the website's favicon; if a favicon is unavailable, the website name still displays.

## Editorial notes
Based on the uploaded SAT Royalty Free Music PowerPoint. Omitted paid-only AudioJungle and the obsolete Vimeo Music Store, and excluded ambiguous or unverified sources such as the old Sound Library page, Moby Gratis and broad SoundCloud searches. Bensound was omitted because its catalogue combines free and paid tracks and the user requested no paid music. Creative Commons is linked as licensing guidance, not as a music provider. This directory includes sites with genuine free-use material, even where free accounts, attribution, item-specific licences or download limits apply. Review terms at the source before use. Last editorial review: October 2026.

## Selection and ordering
Original slide sources with identifiable free-use routes come first in slide order (music, then SFX), followed by extra sources. Paid-only AudioJungle and Vimeo Music Store are excluded; Bensound and Moby Gratis are omitted pending confirmation of current free reuse terms. SoundCloud is only a discovery platform: verify each track. BBC audio has limited free-use terms for public release.
